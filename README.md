## 🚀 Live Vercel Deployment Guide

### Option 1: 1-Click Deploy via Vercel Web Dashboard (Recommended)
1. Go to **[https://vercel.com/new](https://vercel.com/new)**.
2. Sign in with your **GitHub account**.
3. Under **"Import Git Repository"**, select **`weeding_invitation_card`** and click **Import**.
4. Vercel will automatically detect:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. Click **Deploy**.
6. Within 30 seconds, your site will be live with a free SSL URL (e.g., `https://weeding-invitation-card.vercel.app`)!

---

### Option 2: Deploy from Terminal (Vercel CLI)
Run inside the project folder:
```bash
npx vercel
```
- First time: it will prompt to login via browser.
- Select your scope and confirm project settings (just press Enter to accept defaults).
- For production:
```bash
npx vercel --prod
```

## 🛠️ Tech Stack & Features
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion + canvas-confetti
- **Typography:** Cinzel, Playfair Display, Great Vibes, Poppins
- **Mithila Artwork:** Hand-crafted SVG Lotus, Peacock, Mandala, Borders & Paisley
- **Audio:** Shehnai instrumental music with smooth user-gesture autoplay
- **Map Integration:** Google Maps direct navigation for marriage venue
- **Contact:** One-tap Call & WhatsApp direct chat (+91 85077 54988)
